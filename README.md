### Description du projet

La pandémie de Covid-19 a renforcé la méfiance envers les discours officiels en Europe, révélant une crise de confiance envers les institutions démocratiques et scientifiques. À partir des données de l'ESS (2020), ce projet de récupération et de visualisation de données vise à analyser le rôle de la défiance politique et scientifique, de la radicalité idéologique et de l'ancrage territorial dans l'adhésion aux théories complotistes. 

Ce projet s'inscrit dans le cadre du cours "Python pour la data-science" au premier semestre de la 2A de l'ENSAE.

### Organisation du projet

Ce projet se compose de scripts python dans le dossier "scripts" contenant des fonctions et des variables utilisées dans le rapport final qui se lit s'execute de manière linéaire.

Avant de lancer le rapport final, on pensera à installer les dépendances décrites ci-dessous et à **écrire dans le terminal "cd pythonds_2026"**.

### Données

L’European Social Survey (ESS) est une enquête menée dans plusieurs pays européens pour étudier les opinions, les valeurs et les comportements des populations. Ce projet utilise les données de l’ESS Round 10, édition 3.3, collectées à partir de 2020.

- Données et documentation de l'ESS Round 10 - https://ess.sikt.no/en/datafile/f37d014a-6958-42d4-b03b-17c29e481d3d
- Accès aux données des différents rounds: ESS Data Portal - https://ess.sikt.no/en/series/321b06ad-1b98-4b7d-93ad-ca8a24e8788a (création d’un compte nécessaire)
- API : Documentation de l’API ESS - https://ess.sikt.no/en/api
